# SEO Audit Checklist
## Created by Muneeb Ahmad

This checklist covers important SEO factors that help improve website performance and search engine visibility.

### 1. Technical SEO
- [ ] Check website loading speed
- [ ] Check mobile friendliness
- [ ] Verify HTTPS security
- [ ] Check XML sitemap
- [ ] Check Robots.txt file
- [ ] Identify broken links

### 2. On-Page SEO
- [ ] Optimize page titles
- [ ] Write SEO-friendly meta descriptions
- [ ] Use proper heading structure (H1, H2, H3)
- [ ] Optimize image alt text
- [ ] Add internal links
- [ ] Use relevant keywords

### 3. Off-Page SEO
- [ ] Analyze backlink profile
- [ ] Check backlink quality
- [ ] Review referring domains
- [ ] Identify link-building opportunities

### 4. Content SEO
- [ ] Publish useful content
- [ ] Check keyword relevance
- [ ] Improve content readability
- [ ] Update outdated content

### 5. SEO Tools
- Google Search Console
- Google Analytics
- Google Keyword Planner
- Ahrefs
- SEMrush
